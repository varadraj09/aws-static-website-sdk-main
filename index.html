Project Overview

What is this project?

This project demonstrates automated static website hosting using Amazon Web Services. The website files are stored in Amazon S3 and deployed automatically using a Python script built with boto3.

Instead of manually uploading files through the AWS Management Console, the deployment process is automated using the AWS SDK for Python.

How I Host This Website

01

Create / Identify S3 Bucket

The Python deployment script connects to Amazon S3 and identifies the bucket used to host the website.

02

Configure Public Access

The deployment script configures the required S3 public access settings and bucket policy for website content.

03

Enable Static Website Hosting

Amazon S3 is configured to use index.html as the website's default page.

04

Upload Website Files

Python scans the website directory and uploads the HTML and CSS files to the S3 bucket with appropriate content types.

05

Access the Website

Once deployment is complete, the website can be accessed through the Amazon S3 hosted website endpoint or S3 object endpoint.
